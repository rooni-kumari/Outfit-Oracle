# Outfit Oracle 👗

Outfit Oracle is an AI-powered outfit recommendation system developed using Python and Google Colab. It suggests suitable outfits and color combinations based on user preferences.

## Features
- AI-based outfit suggestions  
- Color combination matching  
- Beginner-friendly Python code  
- Works in Google Colab  
- Useful for fashion recommendations  

## Technologies Used
- Python  
- Google Colab  
- Artificial Intelligence  

## How to Run
1. Open the notebook in Google Colab  
2. Run all cells  
3. Enter user input  
4. Get outfit recommendations
